### 6　`New-DataProtectionKey` 與反例

```
New-DataProtectionKey 長度(base64)=44   解碼後 bytes=32
含 + / = 之一 = True                    ← 沒有做字元替換，這是重點
New-SecretPassword 長度=44   只含英數 = True

反例（照 New-RandomPassword 的做法把 +/= 換成 x 之後拿來當金鑰）：
  替換過的字串解碼後 bytes=33
```

★ **33 不是 32**。這正是派工書警告的那個隱性錯誤：`Convert.FromBase64String`
沒有丟例外、`IdentityDataProtector` 的 `_key.Length != 32` 檢查會擋下來，
但若長度剛好湊到 32 就會**默默用一組不是原本亂數的位元組**。所以
`New-DataProtectionKey` 不做替換不是風格選擇。

（harness 會在最後一行的 `Invoke-Nssm` 噴 "not recognized"，那是刻意的：
切片只到那一行為止，harness 沒有定義它，所以**不會真的去呼叫 NSSM**。）

順帶驗 NSSM argv 安全性——每個 `KEY=VALUE` 都必須是單一 argv，不能被空白切開：

```
ConnectionStrings__GreyGray_iam=Host=...;Password=<New-SecretPassword>
  原值含空白/引號 = False   ConvertTo-NativeArgument 需要加引號 = False
Identity__DataProtectionKey=<New-DataProtectionKey>
  原值含空白/引號 = False   ConvertTo-NativeArgument 需要加引號 = False
```

`New-SecretPassword` 產出只剩英數（`+/=` → `x`），Base64 金鑰也沒有空白，
所以連線字串裡的 `;` `=` 不會造成 argv 被切開。**這也是正式機不加
`Include Error Detail=true` 的附帶好處**：那個旗標含一個空白。

### 派工書講到、但我做了不同判斷的兩處（都往「更少」的方向）

## 我發現但沒做的事

### A　★ 正式機那半是真的覆蓋缺口，不要當成「已驗證」

`ops/deploy.ps1` 的新邏輯**沒有在真的 YC 機器上端對端跑過**。這個沙盒沒有 NSSM、
沒有正式機 PostgreSQL、也不該在開發機上真的註冊 Windows service 與排程工作。
我做到的是：

- ✅ 語法（Parser 0 error）
- ✅ 把**交付檔的原文切片**丟進 harness，對真的 PostgreSQL 跑五個案例（§11）
- ✅ 用真的 `service-manifest.ps1` 驗每個服務拿到哪些環境變數（§12）
- ✅ `-ValidateOnly` 兩種參數組合，並確認沒有副作用（§10）
- ❌ **沒有驗**：NSSM `set ... AppEnvironmentExtra` 真的把這 19～21 個鍵寫進服務設定
- ❌ **沒有驗**：三個 Host 以 `GreyGraySvc` 身分被 NSSM 拉起來之後，真的用這些連線字串連上正式機 DB
- ❌ **沒有驗**：正式機的 `Protect-SecretDirectory` 在 `C:\GreyGray\secrets` 上、以部署者身分執行時 ACL 的實際結果

### B　綠界憑證：兩半刻意不對稱，這是設計不是遺漏

  不用再改程式**。

### C　`ops/test.ps1` 與 `start-dev-hosts.ps1` 互斥，而且錯誤訊息很難懂

跑 `ops/test.ps1`（或 `dotnet build`）之前**一定要先收掉三個 Host**，否則會拿到
220 個 MSB3021／MSB3027「檔案正由另一個處理程序使用」。我這一輪踩到一次，
BE-22 的驗收紀錄也提過同一件事。這不是我這一包的範圍（要改的話是 `ops/test.ps1`
或加一支 `stop-dev-hosts.ps1`，兩個都不在 `allow:` 裡），但它會反覆咬人：
**220 個 error 看起來像程式壞了，實際上只是有三個 exe 開著。**

建議下一波考慮：`ops/test.ps1` 開頭偵測 `state\*.pid` 有活著的行程就直接
「請先跑 `ops\stop-dev-environment.ps1`」而不是讓 MSBuild 噴一整片。

### D　`stop-dev-environment.ps1` 沒有「只收 Host、留著 DB」的模式
