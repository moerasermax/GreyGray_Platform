## 逐條自驗

### 派工書 §5 可能寫錯的地方

1. 沒有修改 §3／ACTIVE allow 以外的 Checkout、Ordering、Admin 檔；Admin Host 只在 `M1aEndpoints.cs` 加三個門市欄位與映射。
2. `IDistributedCache` 可直接注入 internal static handler；沒有另開 Garnet 連線、沒有改平台註冊。
3. 冪等指紋使用 Host 內 `CompleteCheckoutFingerprint`，包含原始 `ConvenienceStoreSelectionId` 與原請求欄位，不含解出的門市名稱／地址；沒有改 `BffHttp`。
4. 組合根在 `CvsLogisticsEndpoints.Map` 呼叫 `ReadSettings`。`MerchantId` 空白回傳未設定狀態、不擋開機；有值時其餘壞設定在掛端點時直接丟出清楚訊息。
5. 沒有引用 Payment.Infra private 方法；HTTPS 與 `ecpay.com.tw`／子網域守衛留在 Storefront Host 的 `ReadSettings`，dev 只有明確旗標才放行本機模擬器。
6. 未遇到已證實的綠界中文編碼問題，沒有自行加入轉碼策略。
7. Admin 既有測試沒有因三欄新增而要求行為變更；原值照給，不做 fallback。

### 邊界測試六類與組合根

0. Migration：`0001→0020` 全鏈與重跑、四欄型別長度、checkout／ordering role 實際讀寫、owner 斷言均由 `M1aCoreMigrationTests` 跑過；第 106 行既有 0019 replay 保持不變。
1. 重複與併發：同 cookie 同 key 在票過期後重放原訂單；reply 重送回 `already-used`；同車兩票互不影響；接受的 reply 讀後寫競態已在程式註解記錄。
2. 上下限：Store ID／名稱／地址長度與字元邊界、ExtraData 19／20／21／連字號、Pending 15 分與 Selected 60 分整點到期、非法票的讀票 404 與結帳 422 均有測試。
3. 非法狀態：未設定、壞 form、Merchant／Subtype 偽造後可再成功、Pending 結帳、HomeDelivery 忽略票、舊 code 相容與回應 fallback 均有測試。
4. 權限：跨車讀票 404、跨車結帳 422、無 cookie 讀票 404 且不發 cookie、跨站 reply 無 cookie 仍成功且不發 cookie均有測試。
5. 事件重放：移除新 JSON 欄位的 `checkout.CheckoutCompleted.v1` 經 `EventTypeRegistry` 與真正 `CheckoutCompletedHandler` 建單，新欄為 null；`Cart.ReplayCompletedEvent` 帶新欄位。
6. 部分失敗：reply 快取讀／寫錯誤導回 `unavailable`；checkout 解票錯誤發生在任何下單副作用前，冪等鍵 abandon 後可原 key 重試成功。
7. 組合根與設定：空 Merchant 啟動正常；MapUrl 缺少、非絕對、非綠界網域、錯 subtype 分別測；至少一例經真正 `MapM1aStorefrontEndpoints` 觸發 fail-fast。

### 實作核對

- 快取鍵：`logistics:cvs-selection:` + 選店票 UTF-8 的 SHA-256 lowercase hex；鍵名不含明文票。
- 設定讀取：`src/Hosts/GreyGray.Api.Storefront/Logistics/CvsLogisticsEndpoints.cs` 的 `ReadSettings`，由 `Map` 在組合根呼叫。
- 網址共用：`StorefrontUrls.BuildPublicApiUrl` 組 `ServerReplyURL`；`StorefrontUrls.BuildPublicUrl` 組物流 303 導回網址並同時供既有付款回傳網址使用。
- Reply 手動 `ReadFormAsync`，沒有 `[FromForm]`，成功失敗皆自訂 `SeeOtherResult` 回 303；不讀／不發 cookie。
- 票格式由 `IsValidSelectionId` 共用於 reply、selection GET、checkout；時間只讀 `IClock`。
- `CompleteCheckoutRequest`／`CheckoutCompleted` 只加 init 屬性，EventType 保持 `checkout.CheckoutCompleted.v1`。
- `0020` 使用 `SET ROLE greygray_owner` → ALTER → `RESET ROLE` → checkout／ordering owner 斷言；沒有 grant、跨 schema FK 或回填。
- 模擬器 HTML 由 Core 純函式產生，動態值全部 HtmlEncode；注入反例測試確認 payload 只成為文字，不成為標籤／屬性。
- `start-dev-hosts.ps1` 僅在 `-UseEcpaySimulator` 對 Storefront 注入四鍵；全無採 DEVFAKE 預設、全有沿用、部分直接 throw。
- 凍結契約 `docs/api/openapi.storefront.yaml`、`docs/api/openapi.admin.yaml`、`docs/05-API契約.md` 的 diff 為空。
