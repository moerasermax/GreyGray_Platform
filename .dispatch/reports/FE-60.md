## 逐條自驗

### §1 要做的事

1. 兩支 apiClient 都匯出字面值 `MOCK_API_BASE_URL`；mock 模式固定用 `localhost:5000/5001`，非 mock 維持 env 與原 fallback。正式碼沒有 import handler 或任何 `@greygray/api-client/mock`。
2. 兩支 `mockReady` 都加入 `typeof window !== 'undefined'`；T7 以 mock factory 旗標驗證 node 環境不載入 `MockBootstrap`。
3. admin middleware 在 cookie 檢查前，只於 `NEXT_PUBLIC_USE_MOCK === '1'` 放行；非 mock 分支原有 cookie／redirect 邏輯未改。
4. 新增前台 4 條、後台 7 條測試；每個檔案的 `afterEach` 都呼叫 `vi.unstubAllEnvs()`，每次 `stubEnv` 後都 `vi.resetModules()` 再動態 import。
5. 下方附 Leader mock 走查步驟；本包沒有啟動 dev server。

### §3 T1～T7

- T1：前台 mock + env 指向 `127.0.0.1` 時，`serverApi()` 仍由 `storefrontServer` 攔截；非 mock 的 env probe 也有測試。修正前請求落到 `127.0.0.1` 而紅，修正後 4/4。
- T2：後台同上，由 `adminServer` 攔截；修正前紅、修正後 7/7。
- T3：前台常數等於 `STOREFRONT_BASE_URL`；後台常數同時等於 `handlers.admin` 與 `handlers.admin.auth` 匯出的兩個 `ADMIN_BASE_URL`。
- T4：mock 無 cookie 放行；非 mock 無 cookie 回 307 且 location 以 `/login?from=%2Forders%3Ftab%3Dopen` 結尾；非 mock 有 cookie 放行。修正前 mock 案紅、兩個非 mock 案綠。
- T5：`pnpm typecheck` 與 `pnpm test` 實際 exit 0；條數見「指令與輸出」。
- T6：修改前、後各跑兩個 `NEXT_PUBLIC_USE_MOCK=0` build；static 命中清單逐字相同、manifest key 無差異、沒有 apiClient 指向 `_mock`／`mock/*` 的新 key；admin middleware 產物為 `frontend/apps/admin/.next/server/middleware.js`，環境變數名稱命中 0。
- T7：兩個 app 都以 mock factory 旗標驗證 node 動態 import apiClient 後仍未載入 `MockBootstrap`；先確認修改前兩邊各紅 1 條，再確認修正後全綠。

### 邊界六類

- 重複與併發：不適用；本包只做編譯期環境分支與 middleware 放行，沒有可重複寫入或共享可變交易。
- 上下限：不適用；沒有數值範圍、分頁或容量規則。
- 非法狀態轉移：正式 build 若誤設 `NEXT_PUBLIC_USE_MOCK=1` 會放行登入閘門；實際控制點是後端樹 `ops/build-frontends.ps1` 固定 `0`。本包用 T4 鎖程式分支、T6 鎖正式產物折疊結果，未越界修改控制腳本。
- 權限：T4 覆蓋 mock 無 cookie、非 mock 無 cookie、非 mock 有 cookie三種狀態，尤其鎖住「非 mock 沒 cookie 一定導 `/login`」。
- 事件重放：不適用；沒有事件或 outbox。
- 部分失敗：不適用於交易；T1/T2 以 `onUnhandledRequest: 'error'` 讓 URL 不一致直接紅燈，避免請求意外穿透到真後端而假綠。

### 給 Leader 的 mock 走查步驟

1. 不啟動後端。
2. 在 shell 設 `$env:NEXT_PUBLIC_USE_MOCK='1'`，不要改 `.env.local`；先把兩個 app 既有 `.next` 移到 `%TEMP%` 的暫存目錄，再分別啟動要走查的 app。
3. 前台判準：server log 出現 `[mock] … SSR server 已啟動`，且沒有 `Attempted to call startMock()`；商品頁 view-source 看得到 mock 商品名；瀏覽器 console 出現 `[mock] … worker 已啟動`；Network 沒有送往 `127.0.0.1:500x` 的請求。
