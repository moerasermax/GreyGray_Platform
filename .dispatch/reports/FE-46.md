## 逐條自驗

1. **`CheckoutOrderSummary` 純展示**：標題「訂購明細」；每列 `Thumbnail`（48px，無圖補「無圖」同 `CartLineRow`）、商品名 `line-clamp-2`、規格 `line-clamp-1`、現貨／預購 `Badge`、`× 數量`、列金額 `line.lineTotal`。件數合計 = 各列 `quantity` 相加（整數計數）；商品小計 = `quote?.goodsTotal ?? cart.goodsTotal`；詢價後才畫運費 `quote.shippingFee`、應付總額 `quote.grandTotal`、`ExplainDisclosure`。**未新增任何 API 呼叫、未做任何金額運算**（`subtotalPreview` 未引入，ADR-033 例外沒有擴大）。已觀察：diff 中無新 `api.` 呼叫。
2. **版面**：`main` 在 `lg` 以上 `grid-cols-[minmax(0,1fr)_minmax(320px,380px)]`，左欄表單卡片（配送 → 出貨方式 → 地址／門市＋收件人 → 留言，順序未動）包在一個 `div`，右欄明細 `lg:sticky lg:top-[calc(var(--gg-top-bar-height)+var(--gg-space-4))]`；`lg` 以下 `main` 仍是 flex-col，明細 DOM 位置在表單之前。超過 3 列：前 3 列常駐，其餘進原生 `<details>`（`lg:hidden`），桌面另一份 `hidden lg:flex` 完整列表，兩份互斥。合理推論（未在瀏覽器觀察）：sticky 生效需要 `lg:items-start`，已加。
3. **金額移出配送卡**：配送卡只剩「配送方式＋更換按鈕」與 `quoteError`。`BottomActionBar` 區塊 diff 為零行——應付總額 `quote.grandTotal`、`readiness.reason`、`disabled={!readiness.ready}`、「送出訂單」全部原樣；`PriceDisplay` 仍在檔案內被動作列使用。
