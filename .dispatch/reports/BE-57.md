## 逐條自驗

- `status=open`：真實 ASP.NET Core 路由與 HTTP 請求回 200，服務收到 `SupportTicketStatus.Open`。
- `status=resolved`：真實 ASP.NET Core 路由與 HTTP 請求回 200，服務收到 `SupportTicketStatus.Resolved`。
- 省略 `status`：回 200，服務收到 `null`，代表不篩選。
- `status=bogus`：回明確 400 `application/problem+json`；服務未收到第四次列表呼叫。
- 白名單為精確小寫字串；未使用全域 enum JSON 或 binder 行為。
- 未修改 `SupportTicketStatus`、JSON 設定、Shared.Kernel、API 契約或套件參考。
- 新測試不是直接呼叫 handler，而是啟動最小 `WebApplication`、映射正式 `MapSupportEndpoints`、帶有效後台 session cookie 並送出 HTTP。
- 測試先紅後綠：同一測試修正前因 `open` 得到 400 而失敗，修正後四種輸入全部符合預期。
- 僅執行 `GreyGray.CustomerService.Tests.exe`；migration Testcontainers 類別已排除，未跑其他測試套件。
