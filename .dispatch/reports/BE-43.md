```powershell

elseif ($ingressOutput -match 'Incorrect Usage') { $ingressDetail = "cloudflared 沒有真的驗證（用法錯誤，但仍以 exit 0 結束）：$ingressOutput" }
elseif (-not $ingressSawOk)               { $ingressDetail = "cloudflared 沒有真的驗證（exit 0 但輸出裡沒有獨立一行 OK）：$ingressOutput" }
```

### 第六輪 ①　`Clear-NssmAppParameters`（`ops/lib/Deployment.ps1` 第 176-241 行，新函式）

```powershell

    [Parameter(Mandatory)][string]$ServiceName,
    [Parameter(Mandatory)][scriptblock]$GetAppParameters,

```

流程刻意是「先問再動」：

1. `& $GetAppParameters` 取目前值，正規化後（見下）為空 → **什麼都不做，回 `$false`**。
   剛 `nssm install` 出來的服務就是這樣，所以**第一次部署完全不會寫 registry**。
2. 有值 → `$ServicesRegistryRoot\<svc>\Parameters` 不存在就 throw（不猜要清哪裡）；

3. 再 `& $GetAppParameters` 驗一次，還有值就 throw（「不接受清不掉還往下走」）。回 `$true`。

`Invoke-NativeCommand` 以 UTF-8 解碼，NUL 會讓「其實是空的」看起來非空，
