# BE-56 自驗報告

修 #59 的根因：`GuidIdJsonConverterFactory.CanConvert` 把裸 `Guid?` 誤判成 `XxxId`，
執行期在 `MakeGenericType(typeof(Guid?))` 丟 `TypeLoadException`。

dotnet build tests/GreyGray.Architecture.Tests/GreyGray.Architecture.Tests.csproj -c Release
./tests/GreyGray.Contracts.Tests/bin/Release/net10.0/GreyGray.Contracts.Tests.exe
./tests/GreyGray.Architecture.Tests/bin/Release/net10.0/GreyGray.Architecture.Tests.exe
```

**修之前**（迴歸測試 `Nullable_raw_guid_does_not_throw` 已加進 `WireFormatTests.cs`，
`CanConvert` 尚未加 `Nullable.GetUnderlyingType` 排除）：

```

## 逐條自驗

1. **先紅後綠**：迴歸測試 `Nullable_raw_guid_does_not_throw`（`WireFormatTests.cs`）
   修之前實測丟 `TypeLoadException`（見上方輸出），修完轉綠。✅
2. `GreyGray.Contracts.Tests.exe` 前景跑完，**18 條全過**（原 16 條 ＋ 這次新加 2 條）。✅
3. `GreyGray.Architecture.Tests.exe` 前景跑完，**28 條全過**，沒有既有測試變紅。✅
4. 只改了 allow 範圍內的三個路徑：
   `src/Shared.Kernel/Json/GuidIdJsonConverter.cs`（只在 `CanConvert` 開頭加
   `Nullable.GetUnderlyingType` 判斷式與說明註解，沒有動其餘四個條件、
   沒有動 `CreateConverter` 與 `GuidIdJsonConverter<TId>` 本體）、
   `tests/GreyGray.Contracts.Tests/WireFormatTests.cs`（加兩條測試）、
   `.dispatch/reports/BE-56.md`（本檔）。✅
5. 兩個新測試涵蓋：裸 `Guid?`（null 與有值都要不丟例外、格式跟裸 `Guid` 一致）、
   `CustomerId?`（null 寫成 `null`、有值寫成無連字號 32 碼字串，行為不變——
   這條在修之前就已經是綠的，因為 `XxxId?` 本來就走 `NullableConverter` 這條對的路）。✅
6. 沒有去動 `src/Modules/CustomerService/` 的 `TicketOrderId` wrapper（BE-55 加的），
   它現在仍在生產路徑上運作正常，本包沒有拿掉它。✅
7. `dev` 三個 Host 一律沒有停，全程用 Release 建置與測試執行檔，沒有動 Debug bin。✅
8. 兩個測試執行檔都前景跑到 `TEST EXECUTION SUMMARY` 才結束，沒有掛背景。✅
