## 逐條自驗

### 派工書 §1

1. `param` 最後已加 `[string]$CredentialsDir = ''`；`IsNullOrWhiteSpace` 為 true 時維持原本輸出路徑。
2. 自訂路徑固定依序處理：
   1. `GetUnresolvedProviderPathFromPSPath` 轉絕對路徑，`GetFullPath` 正規化，非根目錄去掉尾端分隔符。
   2. 往上逐層檢查已存在目錄的 `.git`（檔案或目錄均算），終止比較用 `OrdinalIgnoreCase`。
   3. repo 檢查後才從 `$InstallRoot\secrets` 讀原有兩個機密檔。
   4. 自訂目錄不存在時才建立，並立即呼叫 `Protect-SecretDirectory`；已存在目錄不改 ACL。
   5. 完成上述步驟後才設行程環境變數與執行工具。
3. 開頭說明已包含參數用途、只影響新建帳號、建議用不存在的子目錄，以及 `-c` 歧義。
4. 位元組與 Git EOL 實測為 UTF-8 無 BOM、LF。

- 上下限：空字串與純空白維持原行為；相對、含空白已實跑；非根目錄的結尾分隔符會移除。
