## 1. 必做

### 必做 A　純函式 `subtotalPreview`（新檔 `frontend/apps/storefront/app/_lib/subtotalPreview.ts`）

`subtotalPreview(price: Money, quantity: number): Money`：`{ amountMinor: price.amountMinor * quantity, currency: price.currency }`。
守衛：`quantity` 必須是 ≥ 1 的整數、`amountMinor` 必須是 ≥ 0 的整數，否則 throw（不要回 0 湊數）。檔頭註解寫明 ADR-033：只用於顯示、不送後端、購物車以後端為準、其他頁面不准照抄。
測試（新檔 `frontend/apps/storefront/app/_lib/__tests__/subtotalPreview.test.ts`）：60×5＝300、幣別原樣、0 元×N、非整數／0／負數 throw。

### 必做 B　底部列：「N 件 · 小計」

`AddToCartPanel.tsx` 第 135-147 行左側改成兩行：
- 第一行：`{quantity} 件`（小字）＋ 單價（`formatMoney(price)`，有 `unitPriceLabel` 就用它）；
- 第二行：「小計」標籤 ＋ `PriceDisplay amount={subtotalPreview(price, quantity)} size="lg"`。
沒有價格（`!hasPrice`）時左側維持空白（`disabledReason` 已在上方說明），按鈕 disabled 不變。可及名稱要唸得出「5 件，小計 NT$300」（`aria-label` 或視覺順序自然唸出即可）。
把這一塊抽成純呈現元件 `BottomBarSummary`（新檔 `frontend/apps/storefront/app/(shop)/products/[productId]/_components/BottomBarSummary.tsx`，props：`quantity`、`price`、`unitPriceLabel`），`AddToCartPanel` 只負責傳 state。

### 必做 C　商品資訊區：「單價」

`AddToCartPanel` 最上方（規格 chips 之上）加一塊單價：`PriceDisplay amount={price}`（大小比底部列小一號）＋ `unitPriceLabel`（有才顯示）＋ 多規格時顯示已選規格名（`selectedSku.variantName ?? selectedSku.name`）。
沒有價格：預購（`product.mode === 'Preorder'`）顯示「售價在開團時決定」；現貨顯示「尚未定價」（跟既有 `disabledReason` 文案一致，不要兩種說法）。
同樣抽成純呈現元件 `UnitPriceBlock`（新檔，同目錄）。

### 必做 D　規則註記

`frontend/README.md` 第 36 行那一條後面加一句：「唯一例外：商品頁小計預覽（`subtotalPreview`，ADR-033）——只用於顯示，購物車以後端為準。」

### 必做 E　測試與建置

- `BottomBarSummary`／`UnitPriceBlock` 用 `renderToStaticMarkup` 各測：quantity 5 ＋ NT$60 → 有「5 件」與「NT$300」；沒價格 → 沒有任何金額字樣；預購沒價格 → 「售價在開團時決定」。
- 既有 storefront 測試 308 條全過；`pnpm --recursive typecheck`；build 由 Leader 停 dev server 後跑。
