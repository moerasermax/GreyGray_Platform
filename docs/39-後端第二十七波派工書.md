  `cloudflared tunnel create <name>` 產生 `<UUID>.json` 憑證；`C:\GreyGray\cloudflared\config.yml` 寫 `tunnel: <UUID>`、`credentials-file: <path>`、`ingress:` 規則（每條 `hostname`、可選 `path`（正規表示式）、`service`），
  最後一條必須是無 hostname 的 catch-all（`service: http_status:404`）；`cloudflared tunnel route dns <name> <hostname>` 建 CNAME；
  `cloudflared --config <path> tunnel run <name>` 常駐。`cloudflared tunnel ingress validate --config <path>` 可離線驗規則。

## 1. 必做

### 必做 1　`ops/install-tunnel.ps1`（新檔，5.1 可跑，冪等）

參數：`-InstallRoot`（預設 `C:\GreyGray`）、`-TunnelName`（預設 `greygray`）、`-TunnelCredentialsFile`（`cloudflared tunnel create` 產出的 `<UUID>.json` 路徑，必填）、
`-StorefrontHostname`（預設 `greygray.shop`）、`-AdminHostname`（預設 `admin.greygray.shop`）、`-StorefrontApiPort 5000`／`-StorefrontWebPort 5002`／`-AdminApiPort 5001`／`-AdminWebPort 5003`、
`-NssmPath`（預設 `$InstallRoot\bin\nssm.exe`）、`-ServiceCredential`（pscredential，GreyGraySvc）、`-CloudflaredPath`（預設用 `Get-Command cloudflared.exe`）、`-ServiceName`（預設 `GreyGray-Tunnel`）、`-ValidateOnly`。

做的事（每一步都要先查「已存在」再做，重跑不重做）：
1. 建 `$InstallRoot\cloudflared\`；把憑證 JSON **複製**成 `$InstallRoot\cloudflared\<UUID>.json`（從 JSON 讀 `TunnelID`），來源檔不動；目錄與檔案繼承 `$InstallRoot` 的 ACL（GreyGraySvc 讀得到）。
2. 寫 `$InstallRoot\cloudflared\config.yml`（UTF-8 無 BOM、LF）：
   ```yaml
   tunnel: <UUID>
   credentials-file: C:\GreyGray\cloudflared\<UUID>.json
   ingress:
     - hostname: greygray.shop
       path: ^/v1/
       service: http://127.0.0.1:5000
     - hostname: greygray.shop
       service: http://127.0.0.1:5002
     - hostname: admin.greygray.shop
       path: ^/v1/
       service: http://127.0.0.1:5001
     - hostname: admin.greygray.shop
       service: http://127.0.0.1:5003
     - service: http_status:404
   ```
   `path` 是正規表示式（`^/v1/`），順序就是優先序（先 `/v1/` 再其餘）。寫完跑 `cloudflared tunnel ingress validate --config <path>`，不過就 throw。
3. NSSM 登記 `GreyGray-Tunnel`：`Application = <cloudflared.exe>`、`AppParameters = --config <config.yml> --no-autoupdate tunnel run <TunnelName>`、`AppDirectory = $InstallRoot\cloudflared`、
   `Start SERVICE_AUTO_START`、`AppExit Default Restart`、`AppRestartDelay 60000`、`AppThrottle 1500`、`AppStdout`／`AppStderr` 到 `$InstallRoot\logs\GreyGray-Tunnel.*.log`、`AppRotateFiles 1`、`AppRotateBytes 10485760`、
   `ObjectName GreyGraySvc`（密碼只走 `pscredential`，不進命令列以外的任何地方、不印）。已存在就 `set` 更新、不重 `install`。
4. `Start-Service`，等 Running；用 `cloudflared tunnel info <TunnelName>`（需要 cert.pem，執行者是 moera 才有）印連線數；沒有 cert.pem 就只印「服務 Running，連線狀態請看 log」。
5. **不做** `cloudflared tunnel login`、**不做** `tunnel create`（Leader 手動，因為要人點授權）；**不碰** `Cloudflared` 服務、`C:\ProgramData\cloudflared\`、`CloudflaredWatchdog`。
6. `-ValidateOnly`：印解析後的參數與將寫入的 config.yml 內容，不建目錄、不登記服務。
