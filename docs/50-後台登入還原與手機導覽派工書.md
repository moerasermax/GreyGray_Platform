# FE-48 後台登入狀態還原與手機導覽

## 證據與範圍
Leader 2026-09-24 以 Playwright＋本機 Chrome、AI 專用 dev 後台帳號（Owner）實測：
1. **重新整理或直接開連結就掉回儀表板。** 已登入時在 `/orders` 按重新整理（或新分頁開 `/orders/<id>`），導向鏈是 `/orders → /login → /`，原本要去的頁面遺失。cookie `gg_admin_session` 仍在且有效（登入頁隨即判定已登入）。根因：`(dash)/layout.tsx` 只看 `getSession()` 的記憶體快取，而 `login/_lib/session.ts` 自己的註解就寫明「硬重新整理後、還沒問過後端之前，這裡會是 null，即使 cookie 其實還有效」；且導去 `/login` 時沒帶 `from`，登入頁只好回 `/`。
2. **手機寬度沒有任何導覽。** 390×844 登入後只看得到儀表板；`AppShell` 側邊欄是 `hidden md:flex`，md 以下沒有替代入口，其他頁一個都到不了。
知識庫前例（e6619bdf，#30／#32）：拿掉導覽之前一定要有替代出口。只修導覽與登入還原，不動 API、角色規則或頁面內容。
