## 0. 事實（Leader 2026-09-06 逐行查證）

### 0.1 只填三個值，正式憑證會安靜地打到綠界測試站

`src/Modules/Payment/GreyGray.Modules.Payment.Infra/ModuleRegistration.cs` 的 `ReadEcpaySettings`：

- 第 105-107 行：`MerchantId`／`HashKey`／`HashIV` 走 `Required()`（第 169-175 行），缺了會丟例外，**這三個是對的**。
- `src/Modules/Payment/GreyGray.Modules.Payment.Infra/ModuleRegistration.cs:108`-109：`CheckoutUrl` **`??` 預設** `https://payment-stage.ecpay.com.tw/Cashier/AioCheckOut/V5`。
- `src/Modules/Payment/GreyGray.Modules.Payment.Infra/ModuleRegistration.cs:118`-119：`CreditDetailUrl` **`??` 預設** `https://payment-stage.ecpay.com.tw/CreditDetail/DoAction`。

所以拿到老闆的正式商店代號、只換那三個值之後：**系統會拿正式金鑰去打綠界的測試站，而且一個字都不會抱怨。**

### 0.2 現有的網域守衛擋不住這一種錯（它擋的是另一種）

第 152-167 行 `RequireEcpayEndpoint` 只檢查兩件事：`https`，而且 host 是 `ecpay.com.tw` 或 `*.ecpay.com.tw`。
`payment-stage.ecpay.com.tw` **完全符合**。這道守衛是 ADR-029 為了「正式機忘了拿掉 dev 模擬器設定」而設的，它做對了它該做的事；
**「留在測試站」是它從來沒有負責的另一個洞。**（→ §2：不要改它。）

### 0.3 部署腳本自己的訊息就在教人做出這個錯

`ops/deploy.ps1`：

- `ops/deploy.ps1:242`-248：只驗 `MerchantId`／`HashKey`／`HashIV` 三個鍵，`ops/deploy.ps1:245` 的錯誤訊息把格式寫成
  `{ "MerchantId": "...", "HashKey": "...", "HashIV": "..." }`。
- `ops/deploy.ps1:266`-269：也只注入這三個環境變數。

**兩個網址從來沒有被投遞過。** 照著腳本自己的錯誤訊息填 `ecpay.json`（**不在你這棵樹**，它是部署時才放到正式機 `secrets\` 底下的機密檔），做出來的就是 §0.1 那個部署。

### 0.4 這是這個專案已經吃過兩次的形狀

`docs/00-decisions.md` ADR-029 之外，#33（客人在綠界付完款沒有路回商店）的修法就明講過：
**缺設定時明確報錯，不猜一個可能錯的預設值。** 這一包是把同一條原則補到剩下的兩個鍵上。

### 0.5 現在有幾個地方在設這三個鍵

`grep -rn "Payment:ECPay\|Payment__ECPay" src/ tests/ ops/` 目前命中 12 個檔（`src/Modules/Payment/GreyGray.Modules.Payment.Infra/ModuleRegistration.cs` 自己 15 次、

## 6. Leader 的裁決（2026-09-06 第二輪，子代理查證後停下來問）

### 裁決一：必做 E 的建置指令自相矛盾 → 照子代理的建議改

`ops/build.ps1:39` 無條件呼叫整支 `ops/test.ps1`（12 個專案、2026-09-03 實測約 12 分鐘），
而 `.dispatch/reports/README.md` 明文要求「測試分專案前景跑」，因為子代理 harness 單一 tool call 前景上限 600 秒，
超過會被移到背景、**行程一結束整輪就沒了而且 exit code 還是 0**（BE-46 第一輪白跑過一次）。
所以「跑 `ops\build.ps1`」與「分專案前景跑」不可能同時成立。

**裁決**：建置用 `dotnet build .\GreyGray.slnx -c Debug --nologo`；不跑 `ops\build.ps1`、不跑整支 `ops\test.ps1`；
**但架構測試專案必須列在分專案的清單裡並單獨貼出 `Total:`**。不准改 `ops/build.ps1` 本身
（「build.ps1 該不該有一個只建置的參數」是另一個題目，寫進報告即可）。

### 裁決二：`EcpaySimulator` 的註解會過期 → 補授權，只准改那一句

`src/Tools/GreyGray.Tools.EcpaySimulator/Program.cs:13` 附近的註解寫著「換回正式綠界可以不設兩個 URL」，
必做 A 之後那句話就是錯的，**而且會剛好在 E3 換正式憑證那一刻誤導人**——正是這一包要防的那個時刻。
`ACTIVE.md` 補上 `allow: src/Tools/GreyGray.Tools.EcpaySimulator/`，**只准改那一句註解，不准動那支工具的行為**。
