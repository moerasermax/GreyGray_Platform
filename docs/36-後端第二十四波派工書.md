### 必做 2　守衛 `Payment:ECPay:AllowNonEcpayEndpoints`（預設 false）

`ReadEcpaySettings`（`Payment.Infra/ModuleRegistration.cs:102-135`）解析完兩個網址之後：

- 旗標關著時，**兩個網址都必須是 `https`，且 host 是 `ecpay.com.tw` 或以 `.ecpay.com.tw` 結尾**；
  否則丟 `InvalidOperationException`，訊息要點名是哪個鍵、現在的值、以及要開哪個旗標才准。
- 旗標開著才放行任意網址。
- 三個結果要有測試：① `http://127.0.0.1:5009/...` 不開旗標 → 丟例外且訊息含 `AllowNonEcpayEndpoints`；
  ② 開旗標 → 過；③ 兩個網址都不設（走預設 stage）→ 不開旗標也過。

這是正式碼**唯一**新增的分支。正式機忘了拿掉 dev 設定會在 DI 解析期立刻炸，不會默默打到模擬器。

### 必做 3　模擬器 `src/Tools/GreyGray.Tools.EcpaySimulator/`（新目錄）

- `Microsoft.NET.Sdk.Web` 最小 API；csproj 照 `GreyGray.Tools.StaffBootstrap.csproj` 的形狀（`<ModuleLayer>Host</ModuleLayer>`）；

  - `GET /health` → 200。
  - `POST /Cashier/AioCheckOut/V5`（form）：驗 CheckMacValue（錯 → 400，頁面寫 `10200073 CheckMacValue Error`）；
    畫一頁繁中 HTML：顯示 MerchantTradeNo／TotalAmount／ItemName／ReturnURL／ClientBackURL，

  | `CustomField1`～`4` | `""` |
