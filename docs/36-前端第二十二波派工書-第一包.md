## 0. 事實（Leader 2026-09-19 查證）

### 0.1 為什麼要做

超商取貨寄件需要**收件人真實姓名與手機**，但結帳頁不收，後台也看不到——**東西寄不出去**。
使用者 2026-09-19 拍板要加，而且**所有後台員工都看得到明文，不遮罩、不加解鎖按鈕**。

### 0.2 現況

- 結帳頁 `app/(checkout)/checkout/page.tsx`：欄位狀態用 `useState`（約 100-112 行），
  payload 組裝約 266-274 行，可否送出走 `evaluateCheckoutReadiness`（約 340-347 行）。
- **前台**「我的訂單」詳情 `app/(account)/orders/[orderId]/page.tsx`（約 86-87 行）
  已經顯示 `order.shippingAddress.recipientName` 與 `phoneNumber`——但那是**後端即時回查地址簿**來的，
  不是訂單快照（客人改地址，舊訂單會跟著變。BE-54 正在修）。
- **後台**訂單詳情 `apps/admin/app/(dash)/orders/[orderId]/page.tsx`（約 56 行）
  用 `MaskedContactNote.tsx`（這一包做完之後已不存在——見 §1.4）顯示 `customerContactMasked`，
  而那個欄位**後端永遠回 `null`**——後台其實什麼都看不到。那個元件的備註寫的是舊決策。

⚠ 上面行號是 Leader 從盤點取得的近似值，**自己確認，不要照抄行號**。

### 0.3 契約（Leader 已凍結，BE-54 照同一份做）

**`POST /v1/cart/checkout` 的 request 新增兩個選填欄位**

|---|---|---|
| `recipientName` | `string`，1-50 字 | **超商取貨必送**；宅配**不要送**（後端從地址簿抄） |

| 欄位 | 型別 |

**新錯誤碼**：`checkout.recipient-required`（422）——超商取貨但姓名或手機缺漏。
前端要對這個碼顯示看得懂的訊息，不要落到通用錯誤。

`customerContactMasked` 這個欄位**後端保留但仍然回 `null`**，前端不要再用它。

## 1. 要做的事

### 1.1 結帳頁

- **只在超商取貨模式**顯示「收件人姓名」與「收件人手機」兩個欄位。
  宅配模式**不要**顯示，也**不要**送那兩個欄位——宅配的收件人以地址簿為準
  （客人要改就去改地址簿，兩個地方各填一次一定會不一致）。
- 欄位要進 `evaluateCheckoutReadiness`：超商取貨模式下沒填完不能送出。
- 錯誤訊息要具體（「請填收件人姓名」），不要只有紅框。
- ⚠ **手機要檢查格式**：`09` 開頭、共十碼。
  既有慣例是自訂純函式 `validateXxxForm`（範本 `app/(account)/_lib/addressSchema.ts` 的 `validateAddressForm`，
  它對手機只檢查必填與長度 ≤ 20，**沒有格式檢查**）。
  這裡要比它嚴，**因為綠界與超商會擋，格式錯客人就拿不到貨**。
- 欄位旁要有一行說明：**超商取貨時姓名要跟證件一致，不然超商不給領**。

### 1.2 ★ 草稿還原（最容易漏的一項）

FE-33 做的「7-ELEVEN 電子地圖選門市」會**跳出站外再回來**，
靠 `loadCheckoutDraft(cart.id)` 從 `sessionStorage` 還原（約 141-174 行的第一個 `useEffect`）。

**新的兩個欄位一定要進 `currentDraft()` 與還原流程。**
漏了的話：客人填好姓名手機 → 去選門市 → 回來欄位空了 → 重填一次。
**要有測試涵蓋這條路徑。**

### 1.3 前台訂單詳情

`recipientName`／`recipientPhone` 改從**訂單本身**取（BE-54 會提供），
不要再從 `shippingAddress` 取。`shippingAddress` 的其他欄位照舊。

### 1.4 後台訂單詳情

- 顯示 `recipientName`／`recipientPhone` **明文**
- **拿掉 `MaskedContactNote.tsx`**（連元件一起刪，交付後這個檔就不存在了；它的備註寫的是已經不成立的決策）
- ⚠ 不要做「點一下看明文」的按鈕——使用者明確不要那道摩擦
- 出貨的人要能**一眼看到、方便複製**（寄件時要打字），版面上放在明顯的位置
