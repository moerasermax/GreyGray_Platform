## 要求
1. `/terms` 套用 FE-43 已驗收的閱讀版型：`main` 上限 `calc(var(--gg-container-max)*2/3)`，正文段落改 `text-base` ＋ `leading-normal`，節標題、段落、卡片之間用既有 spacing token 建立層級；可參考 `(info)/about/page.tsx` 的寫法，但**不要**把它抽成共用元件。
2. `/terms` 的**內容一個字都不改**：`_content/terms.ts`（屬於仍生效的 FE-37）不在本包範圍；頁面上黃色的「老闆確認項」提示框原樣保留（它是否應在正式站顯示是使用者待決事項，不是本包能決定的），只允許跟著調整寬度與間距。`metadata`、最後更新日期、頁尾相關連結保留。
3. `/login` 容器寬度與註冊頁一致（480px，沿用註冊頁寫法），標題區、表單卡片、錯誤訊息、註冊入口的層級與間距對齊註冊頁（FE-42 已驗收）。Skeleton 寬度跟著一致。
4. `/login` 的行為完全不動：`safeNext`、`registerHref(next)`、錯誤訊息文字與判斷、送出流程、`noValidate`、欄位 label／autocomplete、Suspense 邊界。
5. 兩頁焦點框可見、無水平溢出；不動隱私權頁（屬 FE-37）、註冊頁、共用元件或其他工作包。
