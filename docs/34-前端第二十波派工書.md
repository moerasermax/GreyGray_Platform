**常見問題**

訂購與付款
- Q：預購什麼時候可以下單？　A：每一團都有截團時間。只有在開團期間、還沒截團之前才能送出訂單。
- Q：同一張訂單同時有現貨和預購，要怎麼出貨？　A：下單時可以選「現貨先出貨」（會付兩次運費），或「等預購回國一起出貨」（只付一次運費）。
- Q：可以用哪些方式付款？　A：透過綠界科技（ECPay）線上付款，實際可用的付款方式以付款頁顯示為準。
- Q：送出訂單之後什麼時候要付款？　A：送出訂單後會先建立一筆待付款訂單，請在訂單上顯示的付款期限內完成付款。
- Q：一定要加入會員才能買嗎？　A：可以先把商品放進購物車，送出訂單時才需要登入。

運送與取貨
- Q：運費怎麼算？　A：一口價：超商取貨 NT$60、宅配到府 NT$120、自取 NT$0。
- Q：現貨付款後多久出貨？　A：現貨已經在倉庫裡，付款確認後會安排出貨；實際時間請聯絡客服。
- Q：預購的商品什麼時候出貨？　A：截團後我們出國採購，回國後出貨。

取消與退款
- Q：還沒付款的訂單可以自己取消嗎？　A：可以，到「我的 → 我的訂單」就能取消。
- Q：已經付款的訂單想取消怎麼辦？　A：請聯絡客服協助處理。
- Q：預購有商品沒買到怎麼辦？　A：沒買到的部分會退款，買到的照常出貨。退款會退回原本的付款方式。
- Q：收到商品後可以退換嗎？　A：退換貨的條件請聯絡客服確認。

會員
- Q：怎麼註冊會員？　A：用手機號碼加密碼就能註冊和登入。
- Q：舊平台的帳號還能用嗎？　A：舊平台已經停用，需要重新註冊；舊平台的訂單無法查詢。

**購買流程**

現貨怎麼買
1. 挑選商品：在首頁或商品列表找到想買的現貨商品。
2. 放進購物車：選好規格和數量，加入購物車；也可以按「立即購買」直接前往結帳。
3. 選擇配送方式：超商取貨、宅配到府或自取。
4. 送出訂單：送出時需要登入，還沒有帳號就先註冊。送出後會建立一筆待付款訂單。
5. 完成付款：在訂單上顯示的付款期限內，透過綠界科技線上付款。

預購怎麼買
1. 找到開團：到「開團」看看目前有哪些團、各自的截團時間。
2. 截團前送出訂單：選好商品放進購物車並結帳；截團之後就不能再下單。
3. 選擇出貨方式：同一張訂單也有現貨時，選擇現貨先出，或等回國一起出。
4. 完成付款：在訂單上顯示的付款期限內，透過綠界科技線上付款。
5. 等待採購：截團後我們出國採購，沒買到的部分會退款。
6. 回國出貨：回國後出貨，到「我的 → 我的訂單」可以看進度。

> 「立即購買」是同一波 FE-32 做的；兩包一起部署，所以第 2 步可以直接這樣寫。

**關於我們**

GreyGray 是一家代購小店，提供兩種商品：出國採購的「預購」，以及已經在倉庫、付款確認後安排出貨的「現貨」。

預購是這樣運作的：我們出發採購前先開團，你在開團期間送出訂單；截團後我們出國採購，回國再把商品寄給你。

採購時如果有商品沒買到，沒買到的部分會退款，買到的照常出貨。
