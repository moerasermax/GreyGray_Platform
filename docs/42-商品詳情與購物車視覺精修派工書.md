## 實作要求
1. 商品詳情：桌面媒體與商品資訊採兩欄，寬度與比例平衡；手機維持單欄、媒體大小合理、長標題可折行。缺圖使用中性圖形與明確提示，不捏造商品圖。有圖保持 Thumbnail。標題、說明、預購開團入口與 AddToCartPanel 形成清楚層級，SSR、metadata、API 與商品資料保持不變。
2. 購物車：統一內容寬度與頁首、行項、提示的留白。手機數量控制與行總價有足夠空間，必要時分行；各層加正確 min-width 與長字折行。長商品名、規格、較長金額不能溢出或貼卡邊。縮圖缺圖須有中性辨識；保持移除按鈕、警告及 busy/disabled 語意。
3. BottomActionBar：保留全寬固定背景、原 minHeight 與 safe-area 算式，內層以既有 container token 約束並置中，左右留白與頁面對齊。保留 children 的 flex 排版、外層 className、style 與 HTML attributes 相容性。詳情、購物車、結帳三個使用處都須檢查；不能新增第二條固定導覽或遮住內容。修正註解中把 fixed 誤寫成 sticky 的描述。
4. 保留 PageTopBar 返回與購物車入口、預購開團入口、結帳入口及所有現有可見狀態。過去曾發生隱藏導覽後沒有替代出口的事故；不得只靠直接輸入網址驗收。
5. 只改展示：不改數量/庫存規則、收藏、冪等鍵、請求、報價/金額計算、SSR 資料、契約或結帳行為。不增加 raw hex/任意像素、新依賴、共用抽象或假資料。不要為本包改測試期望。既有 FE-37/38/39 和 Leader dirty 檔保持原樣。
