## 5. 工作包

### FE-17　前台運費文案改從契約來

**相依**：無　**獨佔**：`apps/storefront/app/(checkout)/**`

**問題**：`(checkout)/_lib/labels.ts:13-14` 把運費**寫死成「一口價 NT$60／NT$120」**。
那是 ADR-010 的舊硬編碼，第二波 `d849b13` 就有了，FE-16 回報但不在它的所有權。

**為什麼要修**：運費金額一旦調整，**畫面會跟實際收的不一致，而且不會報錯**。
M3 的「運費規則引擎」一上來這兩行就會變成陳年錯誤，而到時候沒人記得它在那裡。

**必做**

1. 運費金額**從契約來**——`shippingFee` 後端會回，用 `formatMoney()` 渲染。
2. **不要自己算、不要自己拼字串**（鐵則 2）。
   `formatMoney()` 現在對 TWD 會輸出 `NT$`（ADR-028 已落地），所以**不要再手動加前綴**。
3. 文案裡若還需要說明「超商／宅配」的差別，那是**方法**不是金額——
   方法可以是靜態文案，**金額不行**。
4. 搜一遍 `apps/storefront` 還有沒有別的地方把運費金額寫死，一併處理；
   **但只限運費**——別的業務數字（最低訂購額、截團規則）不在這一包，
   發現了寫進「我發現但沒做的事」。

**做法要點**

- 契約沒有回運費的地方（例如購物車還沒結帳前），**不要自己猜 60／120**——
  那就是契約缺口，停下來回報。
- 改完要確認 `NT$` 只出現在 `money.ts` 裡：
  `grep -rn 'NT\$' apps/storefront --include='*.ts' --include='*.tsx'` 應為 0 筆。

**自驗（寫進 `.dispatch/reports/FE-17.md`）**

1. `pnpm --filter storefront typecheck` ／ `test` ／ `build` 全綠
2. `git diff --name-only` —— 只有你擁有的路徑
3. `grep -rn 'NT\$' apps/storefront --include='*.ts' --include='*.tsx'` **應為 0 筆**
4. `grep -rn '60\|120' apps/storefront/app/\(checkout\)/_lib/labels.ts` 沒有運費金額
5. 結帳頁顯示運費的截圖（金額來自契約）
6. 「我發現但沒做的事」：其他寫死的業務數字清單
